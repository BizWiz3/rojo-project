# .lute scripts

These scripts are small helper commands used for local Roblox project workflow.

## `lute build`
Builds the game file using `rojo` and launches it.


## `lute fmt-check`
Validates formatting for both the `.lute` helper scripts and the `src` folder.

## `lute fmt`
Formats the helper scripts in `.lute` and the project source in `src`.

## `lute syncback`
Syncs changes from the `game.rbxlx` file back into the project source.
